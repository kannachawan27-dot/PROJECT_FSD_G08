# Innovation / Evaluation Demo Checklist

1. Start the project with `npm start` and open `http://localhost:3000`.
2. Customize each cake flavor, shape, frosting color and weight. Show the live price update.
3. Enter a cake message and download the SVG cake specification. Open the SVG in a browser to demonstrate that it scales without pixelation.
4. Create a valid booking and show the generated customer receipt.
5. Open the admin login and show the protected dashboard.
6. Search and filter orders, update an order through valid statuses, and print a receipt.
7. Generate the ingredient purchase order and explain that the BOM is a configurable estimate with a 5% buffer.
8. Export bookings to CSV.
9. Run `npm test` and show the integration/security test results.
10. Explain the three-tier architecture, scrypt password hashing, server-side validation, SQLite transaction for capacity and login throttling.

Do not claim that the sample BOM values are certified recipes or that this project guarantees a perfect evaluation score.
